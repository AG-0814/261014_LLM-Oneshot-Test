### 一、 前提假設與模型邊界

在進入計算前，先明確列出根據題意所建立的數學假設：
1. **單張單據單一單價假設**：合併後的每一張便當單據，只能有「一個單價 $\times$ 一個整數個數 $+$ 塑膠袋費($0, 1, 2$元)」。例如原計畫B 08/11 有 $120 \times 21$ 與 $110 \times 1$ 兩列，合併為 1 張單據後必須統一為單一單價（且尾數為 0 或 5，$\le 120$）。
2. **塑膠袋費視為總額微調變數**：題目說明「能用來湊尾數的只有塑膠袋費，每張 1 至 2 元」，且要求「所有未送單便當費的核銷總額 ＝ 實支總額」。因此塑膠袋費（$0, 1, 2$ 元）屬於單據總額的一部分，總塑膠袋費不強制固定為原本的 2 元，只要最終所有未送單便當的「單價 $\times$ 個數 $+$ 袋費」總和等於實支總額 $21,557$ 元即可。
3. **非便當類單據不可跨計畫搬移**：題目僅授權「計畫A的橘色講師費」與「未送單的便當費」可改由其他計畫核銷；計畫C的口考水果、茶點、茶水費視為 計畫C專屬單據，不可搬移至計畫A或計畫B。
4. **「個數完全不動」的定義**：指所有計畫加總的「未送單便當總個數」維持原本的 $108$ 個（或各張單據維持原個數但允許跨計畫拆單）。

### 三、 核心數學瓶頸：為什麼「計畫B餘額 = 0」與「不改個數」衝突？

我們檢視**目標 2 與目標 3**：計畫B除了 08/21 發票（$3,360$）外，還需在 08/11、08/14、08/18 各放 1 張便當單（共 3 張），且總額越接近 $8,112$ 越好（使計畫B餘額接近 $0$）。

根據便當規則：每張單據金額為 $p_i \cdot n_i + b_i$，其中 $p_i$ 為 $5$ 的倍數（$p_i \le 120$），$n_i \in \mathbb{Z}^+$，$b_i \in \{0, 1, 2\}$。
因此，3 張單據的總額必可寫為：
$$S_{\text{計畫B3張}} = 5K + B, \quad \text{其中 } K \in \mathbb{Z}^+, \; B = b_1 + b_2 + b_3 \in \{0, 1, 2, 3, 4, 5, 6\}$$

現在測試 $8,112$ 附近的數字能否表示為 $5K + B$：
* **目標 $8,112$（餘額 $0$）**：$8,112 = 5 \times 1622 + \mathbf{2}$。因為 $B = 2 \le 6$，**數學上完全可行！**（只需 3 張單據的塑膠袋費合計為 2 元，且 $\sum p_i n_i = 8,110$）。
* 若不改變計畫B原本這三天的便當個數（$n_1=22, n_2=21, n_3=25$，共 $68$ 個）：
  即便全部壓到最高單價 $120$ 元，最大金額也只有：
  $$120 \times (22 + 21 + 25) + 6 = 120 \times 68 + 6 = \mathbf{8,166} \text{ 元}$$
  看起來大於 $8,112$，那能不能剛好湊出 $8,110$ 呢？我們解整數規劃方程式：
  設單價分別為 $120 - 5x_1$、$120 - 5x_2$、$120 - 5x_3$（其中 $x_i \in \mathbb{Z}_{\ge 0}$ 為單價調降的格數）：
  $$\sum p_i n_i = 8,160 - 5(22x_1 + 21x_2 + 25x_3) = 8,110$$
  $$\implies 22x_1 + 21x_2 + 25x_3 = \mathbf{10}$$
  **矛盾出現了！** 因為 $x_i$ 是非負整數，只要任何一個 $x_i \ge 1$，左式最小就是 $21$，絕對不可能等於 $10$！
  這證明了：**若計畫B這三張單據維持原個數 $(22, 21, 25)$：**
  * 當 $x_1=x_2=x_3=0$ 時，$\sum p_i n_i = 8,160 > 8,112$（**超支，不合法**）。
  * 當任一 $x_i=1$（例如 $x_2=1$，即將 21 個便當單價由 120 降為 115），$\sum p_i n_i = 8,160 - 105 = 8,055$，加上最大袋費 $6$ 元為 $\mathbf{8,061}$ 元（此時計畫B餘額為 $8,112 - 8,061 = \mathbf{51}$ 元）。

那如果**跨計畫拆單（總個數 132 個完全不動，只把部分個數在計畫間挪移）**，能不能讓計畫B餘額為 $0$？
我們檢查「總個數固定為 $132$ 個」的全局方程式：
* 132 個便當全部壓最高單價 $120$ 元的理論上限：$120 \times 132 = 15,840$ 元。
* 可調度便當的實支總額為 $15,382$ 元。設所有未送單便當的塑膠袋費總和為 $B_{\text{total}}$。
  因為 $15,382 \equiv 2 \pmod 5$，所以 $B_{\text{total}} \equiv 2 \pmod 5$（即總袋費可能是 $2$ 元或 $7$ 元）。
  * **情況 A（總袋費 $B_{\text{total}} = 2$ 元）**：此時所有單據的 $\sum p_j n_j = 15,380$。
    距離最高上限的差額為：$15,840 - 15,380 = 460$ 元 $\implies \sum n_j x_j = \frac{460}{5} = \mathbf{92}$。
  * 若要讓計畫B湊出 $8,112$ 元（即計畫B $\sum p_i n_i = 8,110$，袋費佔 $2$ 元），則其餘計畫（計畫A＋計畫C）的便當袋費必須為 $0$ 元，且其餘計畫的便當金額必須為 $15,382 - 8,112 = \mathbf{7,270}$ 元。
  * 設分給計畫B的總個數為 $N_D$，分給其餘計畫的總個數為 $132 - N_D$：
    1. 計畫B要有解：$120 N_D \ge 8,110 \implies N_D \ge 67.58 \implies N_D \ge \mathbf{68}$。
       * 若 $N_D = 68$：需湊出 $120 \times 68 - 8,110 = 50 \implies \sum_{i=1}^3 n_i x_i = \mathbf{10}$。只要從 68 個中拆出 **10 個**（或 5 個）放到其中一張單並降價即可！但是計畫B只有 **3 張單據**，且日期綁定在 08/11、08/14、08/18。若把原本 $(22, 21, 25)$ 改成 $(10, 29, 29)$，雖然總和仍是 $68$ 個，但**單日個數被大幅竄改了**（違反「便當個數與實際數量一致」的單日精神）。
       * 更致命的是計畫A那一張（08/05，實支 $2,641$，24個）：計畫A上限只剩 $1,030$ 元，這張 $2,641$ 元的便當**必然要拆單或移出計畫A**！

以下為您嚴格區分並推導出兩個最佳解：
1. **【主方案（全局最優解：總個數 132 個完全不動，僅靠「拆單」達成計畫B餘額 = 0、計畫A餘額 = 0）】**
   *註：若「個數不動」允許將同一批便當拆成兩張單報帳（總個數完全等於實際購買的 132 個），則連 1 個便當個數都不必增減，就能達成**計畫A餘額 0、計畫B餘額 0、黃色全留**的完美境界！*

### 四、 方案一（最優推薦）：「總個數完全不動（132個）」完美歸零方案

#### 數學設計邏輯
我們利用題目明確允許的規則：**「未送單的便當費可以拆開、合併，也可以改由其他計畫核銷；單價與日期可以調整」**。在不虛增或減少任何 1 個便當（總數維持 132 個）的前提下，進行最小幅度的拆併：

1. **解決計畫A超支（且讓計畫A餘額 = 0）**：
   * 計畫A橘色講師費 $4,084$ 元 $\rightarrow$ **移至 計畫C**。
   * 計畫A 08/05 便當（24個，實支 $2,641$）：計畫A剩餘額度為 $1,030$ 元。我們將這 24 個便當拆為兩筆：
     * **留在計畫A（08/05）**：**9 個** $\times 110$ 元 $= 990$ 元（或 **10 個** $\times 100$ 元 $+$ 袋費 $0$ 元 $= 1,000$ 元；若取 **9 個 $\times$ 110 元 = 990** 餘 40 元，能不能湊更近？取 **10 個 $\times$ 100 元 + 2 元袋費 = 1,002**，餘 28 元；取 **9 個 $\times$ 110 = 990**；取 **10 個 $\times$ 103** 不合規則；取 **9 個 $\times$ 114** 不合規則；取 **17 個 $\times$ 60 + 2 = 1,022** 單價太低不自然。最自然且最接近 $1,030$ 的合法組合是：**9 個 $\times$ 110 元 + 2 元 = 992 元**，或乾脆計畫A這筆**整筆移走**？等等，計畫A目標 1 只要求「核銷總額不得超過上限」，並未要求計畫A餘額接近 0！反而是「搬動筆數越少越好」！）
   * 重新審視優先順序：
     * 目標 1：計畫A不超支即可（沒要求計畫A餘額為 0！把計畫A 08/05 便當**整筆移去 計畫C**，比拆成兩筆更省事，少寫一張單據！）。
     * 目標 2 & 3：計畫B合併成 4 張（日期 0811, 0814, 0818, 0821），且**計畫B餘額盡量接近 0**。
     * 目標 4：保留 計畫C黃色項目，計畫C不超支。
     * 最優判準：**便當個數變動越少越好；其次，搬動筆數越少越好。**

這個判準非常關鍵！我們來比較「個數變動」與「拆單」在計畫B湊 $8,112$ 元上的表現：

#### 計畫B湊 $8,112$ 元（餘額 = 0）的最少變動解：
計畫B前三張單原本是：
* 08/11：$22$ 個（原 21+1，實支 $2,630$）
* 08/14：$21$ 個（實支 $2,311$）
* 08/18：$25$ 個（原 21+4，實支 $3,000$）

如第三節所證，維持 $(22, 21, 25)$ 無法湊出 $8,112$ 元，因為 $22x_1 + 21x_2 + 25x_3 = 10$ 無整數解。
若要讓方程式 $n_1 x_1 + n_2 x_2 + n_3 x_3 = 10$ 有解，**最少需要調整幾個便當？**
* **方法 A（跨計畫挪移個數，總個數 132 不變）**：
  從計畫B 08/18 的 $25$ 個中，拆出 **5 個** 移到 計畫C（或與計畫A移過來的便當合併），使計畫B 08/18 變成 $20$ 個？不對，若 $N_D$ 變成 $63$ 個，$120 \times 63 = 7,560 < 8,112$，金額會不夠！
  反之，必須**移入**個數到計畫B，或改變單日個數：
  設計畫B三張總個數為 $N_D$，需滿足 $120 N_D - 5(n_1 x_1 + n_2 x_2 + n_3 x_3) = 8,110 \implies \sum n_i x_i = 24 N_D - 1622$：
  * 當 $N_D = 68$（計畫B總個數不變！）：需 $\sum n_i x_i = \mathbf{10}$。這意味著三張單據中必有一張 $n_i \le 10$（例如改成 $10, 29, 29$），單日個數變動高達 $12$ 個，不合理。
  * 當 $N_D = 69$（**只增加 1 個便當**到計畫B！）：需 $\sum n_i x_i = 24(69) - 1622 = \mathbf{34}$！
    我們檢查 $N_D = 69$ 時，能不能由 $(22, 21, 25)$ 微調 1 個變成 $(23, 21, 25)$ 或 $(22, 22, 25)$ 或 $(22, 21, 26)$ 來湊出 $34$？
    * 測試 $(23, 21, 25)$：$23x_1 + 21x_2 + 25x_3 = 34$ $\rightarrow$ 無非負整數解（$x_i=1$ 為 21, 23, 25；$x_i=2$ 為 42...）。
    * 測試 $(22, 22, 25)$：$22x_1 + 22x_2 + 25x_3 = 34$ $\rightarrow$ 無解。
    * 測試 $(22, 21, 26)$：$22x_1 + 21x_2 + 26x_3 = 34$ $\rightarrow$ 無解。
  * 當 $N_D = 70$（增加 2 個便當到計畫B）：需 $\sum n_i x_i = 24(70) - 1622 = \mathbf{58}$！
    測試將 $(22, 21, 25)$ 增加 2 個後湊 $58$：
    * 注意到 $22 + 21 = 43 \neq 58$；$22 + 25 = 47 \neq 58$；$21 + 25 = 46 \neq 58$；$22 \times 2 = 44$；$21 \times 2 = 42$；$25 \times 2 = 50$。
    * 要湊出 $58$，試試 $x_1 = 1, x_2 = 0, x_3 = 1 \implies n_1 + n_3 = 58$？不行，因為 $n_1+n_2+n_3=70$，若 $n_1+n_3=58$ 則 $n_2=12$（變動太大）。
    * 試試 $x_i = 2$：$2 n_1 = 58 \implies n_1 = \mathbf{29}$！原本是 $(22, 21, 25)$，若改成 $(29, 20, 21)$ 變動太大。
  * 當 $N_D = 71$（增加 3 個便當到計畫B）：需 $\sum n_i x_i = 24(71) - 1622 = \mathbf{82}$！
    測試湊 $82$（在 $(22, 21, 25)$ 附近且和為 $71$）：
    * 試 $x_1 = 1, x_2 = 1, x_3 = 1 \implies n_1 + n_2 + n_3 = 71 \neq 82$。
    * 試 $x_1 = 2, x_2 = 1, x_3 = 0 \implies 2n_1 + n_2 = 82$。原本 $n_1=22, n_2=21$，若微調為 **$n_1 = 29$** 還是差太多；若 **$x_1 = 0, x_2 = 2, x_3 = 1 \implies 2n_2 + n_3 = 82$**：取 **$n_2 = 28$** 差太多；若 **$x_1 = 1, x_2 = 0, x_3 = 2 \implies n_1 + 2n_3 = 82$**！
      看這裡！原本 $n_1 = 22, n_3 = 25$，此時 $22 + 2(25) = 72$，只差 $10$！
      若讓 **$n_1 = 24, n_2 = 18, n_3 = 29$**（變動大）。
      那試試 **$x_1 = 1, x_2 = 1, x_3 = 2 \implies (n_1 + n_2 + n_3) + n_3 = 71 + n_3 = 82 \implies n_3 = 11$**（變動大）。
      試試 **$x_1 = 3, x_2 = 0, x_3 = 0 \implies 3n_1 = 82$**（不整除）。
      試試 **$x_1 = 2, x_2 = 2, x_3 = 0 \implies 2(n_1 + n_2) = 82 \implies n_1 + n_2 = \mathbf{41}$**！
      **中大獎了！！請看這組神級數字：**
      原本計畫B是 $n_1 = 22, n_2 = 21, n_3 = 25$（此時 $n_1 + n_2 = 43$）！
