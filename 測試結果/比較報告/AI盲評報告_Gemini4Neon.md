## 四、跨題深度洞察與選型建議

1. **Agent 框架基準對照 (`Opus 5.5` vs `Sonnet 5.5`)**
   工具能顯著拉高外部事實查證 (題二)、程式組合求解 (題四) 與印刷級出圖交付 (題一) 的上限，但前提是基座模型本身具備高審美、仔細核圖與避免模板化的能力。`Opus 5.5` 在工具加成下形成跨維度領先，成為整場評測的黃金標準；相對地，`Sonnet 5.5` 雖藉助工具拿下數學配平第二名，卻因鍵帽注音視覺誤判 (錯看為「ㄆ」)、明信片背面文字遮擋及作文模板化，在總榜中落後多位無工具輔助的純 API 模型。

2. **純 API 三大強者性格對照 (`GPT-6.2 Sol`、`GPT-6.1 Sol`、`Gemini 4 Neon`)**
   - **追求「零幻覺、最高寫作靈魂與穩健心算」**：首推 **`GPT-6.2 Sol`**。本場唯二兩題高度仰賴原創思辨與簡潔心算的難題 (國寫作文奪全場第一、Excel 配平不寫冗稿即奪純 API 第一) 皆展現過人實力，且所有題目極度誠實克制、零語系混雜與零過度延伸。
   - **追求「全場景零弱點、商業與文字思辨嚴謹」**：首推 **`GPT-6.1 Sol`**。五題全數維持前段水準，商科銳評奪純 API 冠軍、國寫亞軍，唯一可扣分處僅為多模態題微幅簡體漏字與鍵帽細節遺漏，屬於極為穩健的純 API 全能型選手。
   - **追求「視覺設計、多模態實務辨識與社群商業長文」**：**`Gemini 4 Neon`** 在完測的四道題目中表現冠絕純 API 組 (四題均分 89.5，含純 API 題一冠軍、題二冠軍、題五亞軍、題三季軍)；惟在超長組合推理題觸發 32k token 截斷未完成輸出 (與 `Gemini 4 Carbon` 的 16k 截斷同屬長推理輸出控管警訊)，若於實務導入數學或大規模規劃任務，須特別注意推理長度與工具輔助配置。

3. **客戶端 App 特例 (`Gemini 4 Argon (App)`)**
   於明信片單題中繳出 **90 分 (全 10 模第 3 名)** 的亮眼成績，無論對原圖焦點的保留、雙角色模組的創意融合或卡片正反面的印刷感，皆已逼近頂級 Agent 基準 (`Opus 5.5`) 與最強純 API (`Gemini 4 Neon`) 水準。
