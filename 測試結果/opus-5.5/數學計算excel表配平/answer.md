假設：三個計畫的上限由表尾反推，且「發票」便當單據連所屬計畫也不搬動，以下依此作答。

## 一、讀表與前提假設

**上限反推**

| 計畫 | 業務費小計 | 表尾差額 | 上限 | 已送單 | 當下剩餘 |
|---|---|---|---|---|---|
| 計畫A | 35,695 | 超出 5,695 | 30,000 | 26,095 | 3,905 |
| 計畫B | 36,829 | 餘 171 | 37,000 | 25,528 | 11,472 |
| 計畫C | 90,567 | 餘 7,433 | 98,000 | 79,705 | 18,295 |

三個計畫合計剩餘空間 33,672，未送單合計 31,763，總共只多出 1,909 元可以分配。

**我採用的假設**

1. 兩張「(發票)」便當 (計畫A 0804 的 115×25=2,875、計畫B 0821 的 120×28=3,360) 的日期、單價、個數、金額與所屬計畫都不動。
2. 可調整的「未送單便當池」只動到計畫A 0805 (24 個，實支 2,641) 與計畫B 0811/0814/0818 (22+21+25=68 個，實支 2,630+2,311+3,000=7,941)。池內合計 92 個、實支 10,582。計畫C原有的膳費列全部不動。
3. 一張單據只用一個單價：金額 = 單價×個數 + 塑膠袋費。單價 ≤120 且尾數為 0 或 5；塑膠袋費為 0、1 或 2 元。
4. 「個數不動」的定義：每一盒便當都要報在某一張單據上 (總數 92 不變)，每張單據的個數等於它涵蓋的原始列個數。拆開某一列、把其中幾盒併到別張單據，都算個數不動。把某一天的便當報到另一天的單據上，就算「個數變動」。
5. 「搬動筆數」是指移到其他計畫核銷的項目數。
6. 計畫A橘色講師費 (2000×2+84=4,084) 的日期 11509XX 維持不變。

## 二、關鍵推導

1. **計畫A講師費一定要搬走**：4,084 > 當下剩餘 3,905，計畫A無法單獨容納。計畫B在發票之外只剩 8,112 元可報便當，自己的便當就要用掉 7,941，所以講師費只能移到 計畫C (剩餘 7,433 ≥ 4,084)。
2. **計畫A便當也要搬一部分**：計畫A扣掉發票 2,875 之後只剩 1,030，而 0805 便當實支 2,641，至少要移出 1,611。
3. **計畫B剛好打平的條件**：除了發票那張，0811、0814、0818 三張合計必須正好等於 37,000 − 25,528 − 3,360 = 8,112。因為單價都是 5 的倍數，所以 8,112 = 5×1,622 + 2，也就是塑膠袋費合計 2 元，並且 Σ(個數×單價/5) = 1,622。
4. **個數完全不動時做不到 0**：三張單據若只放各自日期的 22、21、25 個，最多 68×24 = 1,632，比目標多 10。要湊到 1,622，就得用 22、21、25 的倍數組出 10，這不可能。計畫A便當最多能帶 3 盒進計畫B，因為剩下的 21 盒還要承擔 2,470 元，而 2,470/21 已接近 120 的上限。程式窮舉了全部組合，個數完全不動時計畫B最好只能到餘額 6 元。
5. **只改 1 盒就能歸零**：把 0814 的 1 盒改報在 0818 (0814 為 20 個、0818 為 25+1+3=29 個)，就有正好 8,112 的解。窮舉結果顯示，餘額要歸零，至少得變動 1 盒，不存在 0 盒的解。

### 驗算

| 計畫 | 核銷總額 | 上限 | 餘額 |
|---|---|---|---|
| 計畫A | 26,095 + 2,875 + 550 = **29,520** | 30,000 | **480** |

| 計畫C | 79,705 + 10,862 + 4,084 + 1,920 = **96,571** | 98,000 | **1,429** |

- 便當池金額：550 + 2,530 + 2,101 + 3,481 + 1,920 = 10,582，等於實支 2,641 + 2,630 + 2,311 + 3,000 = 10,582，沒有多報也沒有少報。

- 三計畫總額：29,520 + 37,000 + 96,571 = 163,091，和原本的 35,695 + 36,829 + 90,567 相同。總餘額 1,909 = 480 + 0 + 1,429。
- 所有單價都 ≤120 且尾數為 0 或 5，塑膠袋費都在 0 到 2 元之間。

### 主方案的代價

1. **個數變動 1 處**：0814 報 20 個 (實際 21 個)，0818 報 29 個 (25 個來自 0818 本身，1 個來自 0814，3 個來自計畫A 0805)。總數 92 不變。
2. **搬動 3 筆**：講師費 4,084 移到 計畫C；計畫A 0805 便當拆成三段，5 個留在計畫A、3 個併入計畫B、16 個移到 計畫C。
3. **各單據單價和實支不一致**：例如 0811 實支 2,630、報 2,530；0818 加上移入的盒數後報 3,481。只有池子總額和實支相等，個別單據的單價是為了配平重新分配的。
4. 計畫A 0805 原本那 1 元塑膠袋費不再單獨出現，已經算進池子的總額裡。

| 方案 | 計畫B餘額 | 個數變動 | 搬動筆數 | 計畫A餘額 | 計畫C餘額 | 黃色項目 |

**A：個數完全不動的最佳解 (計畫B餘額 6)**

- 計畫A：0805 便當留 3 個，105×3 = 315。
- 計畫B：0811 為 120×22+2 = 2,642；0814 為 100×21+2 = 2,102；0818 為 120×28+2 = 3,362 (25 個加上計畫A移入的 3 個)；0821 發票 3,360 不動。
- 計畫C：講師費 4,084，加上計畫A便當 120×18+1 = 2,161。
- 驗算：計畫A 29,285，計畫B 36,994，計畫C 96,812。便當池 315 + 2,642 + 2,102 + 3,362 + 2,161 = 10,582，個數 3 + 22 + 21 + 28 + 18 = 92。
- 這是「個數完全不動」條件下程式窮舉得到的最小餘額。

**B：盒子不跨計畫 (計畫B餘額 51)**

比假設 4 更嚴格的解讀：計畫B的單據只能放計畫B自己的 22、21、25 盒。

- 計畫B：120×22+2 = 2,642、115×21+2 = 2,417、120×25+2 = 3,002，合計 8,061。
- 計畫A 0805 便當 24 個整筆移到 計畫C，報 105×24+1 = 2,521。計畫A只剩發票便當。
- 講師費移到 計畫C。

**C：搬動最少、計畫A便當原封不動 (計畫B餘額 171)**

- 講師費 4,084 和計畫A 0805 便當 (110×24+1 = 2,641) 原封不動移到 計畫C。
- 計畫B各報實支總額 7,941，可拆成 110×22 = 2,420、120×21 = 2,520、120×25+1 = 3,001。
- 這個方案沒有跨計畫挪金額。代價是計畫B留下 171 元沒有用掉。

**其他說明**

- 如果講師費改移到計畫B，計畫B便當就得大量移到 計畫C，搬動筆數只會更多，所以不建議。
- 四個方案的 計畫C都沒有超支，黃色 4 筆 (3,303) 全部保留，最少還有 708 元餘裕。
- 如果發票便當可以改由其他計畫核銷 (假設 1 放寬)，計畫A就多出 2,875 的空間。不過計畫B的瓶頸在於單價上限和個數，放寬這點不會讓「個數完全不動」的結果比餘額 6 更好。
