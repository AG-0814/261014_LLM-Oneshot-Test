## 備註

- 系統回報的 tokens 是單一數字，沒有拆分輸入、輸出與思考 token，也沒有附費用。數字內含 Claude Code 本身的系統提示與工具定義 (每個子代理都有，估計占數萬 tokens)，所以不能直接和 API 呼叫的 prompt_tokens 比較。
- 兩邊作文題的條件不同：Sonnet 5.5 無法把 PDF 轉成圖片，改用文字擷取作答；Opus 5.5 直接讀到 PDF。
